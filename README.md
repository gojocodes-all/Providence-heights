📖 About The Project

This project is a modern school website designed to provide students, parents, staff, and visitors with easy access to important information about Providence Heights Secondary School.

The website focuses on accessibility, responsiveness, clean design, and an intuitive user experience across desktop, tablet, and mobile devices.

---

✨ Features

- Responsive design for all screen sizes
- Modern and professional user interface
- School information and history
- Academic programs section
- Facilities showcase
- Staff and leadership profiles
- Gallery section
- Contact information
- Fast loading performance
- Mobile-friendly navigation

## Development

Install the locked toolchain and run the dependency-free validation suite:

```bash
npm ci
npm run validate
```

The validation command syntax-checks the site JavaScript and runs regression
tests for the mobile navigation's markup, visual state, accessible state,
Admissions link, and Escape-key focus behavior. Pull requests and updates to
`main` run the same checks in GitHub Actions.
